# Passenger Counter APP

## Uses HTML, CSS and JS

## Requirements

1. Build it from "scratch"
2. Follow the design spec
3. Deploy to the web

## Specification

1.  Title (choose something interests you)
2.  Background image
3.  Font (from list)
4.  Button colors and appearance (width, border, etc)
5.  Wrap a div around the HTML, add a max width
